💡 How to Use This Website

  • Select your provider and connection type.
  • Test at different times of day to compare your experience.
  • Rate service based on your actual experience.
  • Never include passwords or other sensitive information in a report.

📢 About This Project

This project aims to help people share Internet experiences and identify service problems by area. Ratings should be shown with the number of responses and location details so that a small number of reports is not misleading.

Before public launch, add a backend, database, data protection, and a process for tracking and responding to complaints.
